# residence-operations-automation
A workflow automation project designed to streamline the tracking and return process of residence safety caps used by Community Advisors (CAs).  

The system automates:

cap return tracking
overdue reminder notifications
QR-code based submissions
administrative workflow management

# The project was designed for real-world use within university residence operations.

Features
Current Features
Google Form-based cap return submission
Automated Excel data tracking
QR-code enabled return workflow
Automated reminder emails using Microsoft Power Automate
Overdue cap detection
Supervisor-friendly administrative workflow
Mobile-friendly submission process
Technologies Used
Google Forms
Microsoft Power Automate
Microsoft Excel Online
Google Apps Script
QR Code Automation
